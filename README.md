# Minus One Card Game
A strategic card game where players compete to achieve early survival through tactical card play and resource management.

## Overview
**Minus One** is a multiplayer strategy game where players use numbered cards (1-8) to score points across multiple rounds.

***Lowest unique card wins***

Players must balance immediate victories with long-term survival as the game features survival rounds where **the highest scorer safely escapes the game**.

## Core Mechanics
- **Card Play**: Select 2 cards and submit one of them. Unused card becomes temporarily unavailable for next round
- **Scoring**: Winner gains points equal to card value + 1 Victory Token
- **Survival**: At rounds 3 and 6, the highest scorer **wins and leaves the game**
- **Strategy**: Accumulate victory tokens and points before survival rounds for early escape

## Technical Stack
- **Unity**: C# scene-based architecture with drag-and-drop UI and visual transitions
- **Aseprite**: Pixel art created with Aseprite for card designs and UI elements

## How To Play
1. **Setup**: 4 players, each with cards 1-8
2. **Round**: Choose 2 cards → reveal → select final card → lowest unique wins
3. **Survival**: **Early escape opportunities** at rounds 3 and 6 based on points + Victory Tokens
4. **Victory**: **Achieve 1st place in survival rounds to safely exit the game**

**Key Strategy**: Accumulate maximum points and tokens before survival rounds to secure early escape
